## How the pages link together

```
fun-activities (hub) ──> games, greeting-cards, memory-lane
games article ──> /games/ ──> greeting-card article ──> /greeting-cards/
/faq/ ("Using this website") ──> both articles
```

Each article links to its tool. Each tool page has FAQs, and the tools link to each other.

## Ways to earn links with these tools

- Activity directors at senior centers and libraries often keep "free online activities" resource lists. Pitch the coloring book and memory game as free, ad-free and no sign-up.
- Area Agency on Aging and senior center newsletters (see `04-backlink-action-plan.md`, #10 and #15).
- Share each tool on Facebook, Pinterest and Instagram with a finished example (a colored picture, or a sample card).

## Guardrails

- No claims that games prevent or treat dementia or memory loss. Say "relaxing", "keeps your mind busy" or "fun".
- Card-maker privacy wording should stay exactly what the tool does: photos stay on the device unless the user shares them.
